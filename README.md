## Featured projects

### [StudyPal](https://github.com/Bram-cat/Studypal)
Local UPEI study assistant with a retro dashboard, Moodle sync, OpenClaw runtime, and grounded course chat.  
**Stack:** JavaScript, Bun, local-first tooling, AI assistant workflows

### [LoveLock](https://github.com/Bram-cat/lovelock)
React Native / Expo mobile app for numerology, astrology, compatibility, and relationship-focused experiences.  
**Stack:** React Native, Expo Router, TypeScript, mobile UI/UX

### [Dreamboard](https://github.com/Bram-cat/Dreamboard) · [Live](https://dreamboard-six.vercel.app)
AI-powered visual board / creative planning app for turning ideas into generated visual directions.  
**Stack:** Next.js, TypeScript, Google GenAI, Radix UI

### [LawScanner](https://github.com/Bram-cat/lawscanner)
Legal document scanner and summarizer with OCR/document-processing integrations and AI-powered insights.  
**Stack:** Next.js, TypeScript, Anthropic SDK, AWS Textract, document AI pipeline

### [AlumniPath / UPEI Student App](https://github.com/Bram-cat/upei_student_app) · [Live](https://upei-student-app.vercel.app)
Career GPS for students: connects students with alumni who are a few steps ahead and can give practical direction.  
**Stack:** Next.js, TypeScript, Clerk, modern full-stack UI

### [Solar Panel Advisor](https://github.com/Bram-cat/team-green-coders) · [Live](https://team-green-coders.vercel.app)
Solar assessment web app that helps homeowners evaluate roof potential using uploaded images and address input.  
**Stack:** Next.js, TypeScript, Gemini, Clerk, modern UI components
